I am Jorge Becerro, a Software Engineer, and for the last several years I have been working as a Software Architect /
Tech Lead within the Near Real Time (NRT) Integration team at Avolta.

My experience is mainly focused on backend technologies, which I have been learning and applying since the beginning of
my career. Most of this background is centered on Java environments, from monoliths to microservices with Spring Boot
and OpenAPI, Kafka/Confluent ecosystems for integration and streaming, and data processing with Spark and Kafka Streams.
I have also worked continuously with container-oriented systems (Docker, Kubernetes, Helm), CI/CD integration (Jenkins,
Bamboo, Azure DevOps Pipelines, GitHub Actions, SonarQube), and cloud environments on AWS and Azure.

In day-to-day work, I aim to apply development best practices through design patterns at both application and
integration levels, while designing fit-for-purpose architectures aligned with industry standards.

For the past few years, I have also incorporated AI into the software development lifecycle as a regular team strategy,
playing an important role in shaping a practical framework around it.

Beyond the technical side, I actively contribute to project analysis and planning, technical interviews, profile
mentoring, and internal/external training.

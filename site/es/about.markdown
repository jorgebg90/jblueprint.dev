Soy Jorge Becerro, Ingeniero Informático y desde hace años para acá desempeño el rol de Arquitecto de software / Tech
lead dentro del equipo de Integración en Near Real Time (NRT) en Avolta.

Mi experiencia se centra especificamente en tecnologías backend, las cuales he ido aprendiendo y descubriendo desde el
comienzo de mi carrera. Entre ellas, mayoritariamente se han basado en entornos Java, desde el uso de monolitos hasta
microservicios con Spring Boot y OpenAPI, ecosistemas Kafka/Confluent para integración y streaming, y procesamiento de
datos con Spark y Kafka Streams. También he trabajado de forma continuada con sistemas orientados contenedores (Docker,
Kubernetes, Helm) haciendo uso de la integración mediante CI/CD (Jenkins, Bamboo, Azure DevOps Pipelines, Github
Actions, SonarQube) y entornos cloud en AWS y Azure.

Dentro del día a día intento aplicar buenas prácticas de desarrollo, con el uso de patrones de diseño a nivel de
aplicación como de integración así como el diseño de arquitecturas a medida siguiendo las buenas prácticas del mercado.

Desde hace unos años para acá uso de manera habitual como estrategia de equipo la integración de la IA dentro del ciclo
del desarrollo del software, siendo un actor importante de cara a tener un framework de trabajo sobre este.

Además de la parte técnica, participo activamente en análisis y planificación de proyectos, entrevistas técnicas,
mentoría de perfiles y formación interna/externa.

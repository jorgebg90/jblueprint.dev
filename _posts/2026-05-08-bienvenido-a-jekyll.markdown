Encontraras esta entrada en tu directorio `_posts`. Editala y vuelve a construir el sitio para ver tus cambios. La forma mas comun es ejecutar `jekyll serve`, que inicia un servidor local y regenera el sitio cuando actualizas archivos.

Jekyll requiere que los archivos de publicaciones sigan este formato:

`YEAR-MONTH-DAY-title.MARKUP`

Donde `YEAR` es un numero de cuatro digitos, y `MONTH` y `DAY` son de dos digitos. `MARKUP` representa la extension del formato usado. Luego agrega el front matter necesario.

Jekyll tambien ofrece soporte para fragmentos de codigo:

{% highlight ruby %}
def print_hi(name)
  puts "Hi, #{name}"
end
print_hi('Tom')
#=> prints 'Hi, Tom' to STDOUT.
{% endhighlight %}

Consulta la [documentacion de Jekyll][jekyll-docs] para mas informacion. Puedes reportar errores en el [repositorio de GitHub de Jekyll][jekyll-gh].
